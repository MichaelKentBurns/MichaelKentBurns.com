Easily manage and update all your WordPress sites hosted on Cloudways.

== Description ==

The Cloudways WordPress Manager plugin lets you remotely manage and update all your WordPress sites from one centralized dashboard.

Co-developed with WP Remote.

= Features =

* Completely free to use.
* Manage unlimited WordPress sites.
* Monitor and update all your plugins and themes.


= Important Note: Auto-Updates =

**Auto-updates will be disabled when this plugin is active.** This is intentional behavior for performance optimization and stability reasons. The plugin disables WordPress automatic updates to ensure optimal performance and prevent conflicts during remote management operations.
